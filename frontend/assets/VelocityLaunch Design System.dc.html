10. Directives d'Implémentation

Pour Claude Code

1. Utilise toujours les variables CSS :

--color-primary: #9184d9;
--color-indigo: #6366f1;
--color-cyan: #06b6d4;
--color-bg: #0f1419;
--color-text: #e9e9ed;
--color-muted: #a1a1a6;

2. Spacing scale (pour padding/margin/gap) :

--space-xs: 4px;
--space-sm: 8px;
--space-md: 12px;
--space-lg: 16px;
--space-xl: 20px;
--space-2xl: 24px;

3. Border Radius :

--radius-sm: 4px;
--radius-md: 6px;
--radius-lg: 8px;
--radius-xl: 12px;
--radius-full: 50%;

4. Shadow :

--shadow-sm: 0 1px 2px rgba(0,0,0,0.3);
--shadow-md: 0 4px 6px rgba(0,0,0,0.3);
--shadow-lg: 0 10px 15px rgba(0,0,0,0.3);

5. Règles de Design :

  • Tous les textes utilisent Inter (system fonts)
  • Contraste minimum AAA pour l'accessibilité
  • Les boutons primary sont des outlines avec border, jamais des fills
  • Les liens ont une couleur d'accent avec underline subtil
  • Utilisez gap pour espacer les flex/grid items (pas de margin individuelle)
  • Les inputs/fields ont un focus visible avec outline à 2px
  • Pas de couleurs fixes — utilise toujours les ramps de couleurs
